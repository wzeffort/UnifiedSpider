网页资料收集助手

把网页上的内容保存下来，方便查看、整理和分享。

①把网址粘贴到这里

打开您想保存的网页，复制浏览器顶部的网址，再粘贴到下面。

输入网址后，这里会显示是否有可用的本站浏览状态。

尚未获取 Cookie，请先输入网址。

首次连接 / 扩展未就绪时看这里

下载 Cookie-Editor 本机收集版（Edge / Chrome，非官方修改版）并解压。请先停用旧的独立连接扩展，避免重复响应。

Edge 打开 edge://extensions；Chrome 打开 chrome://extensions。开启开发人员模式，点击“加载解压缩的扩展”，选择含 manifest.json 的 CookieEditor-Collector 文件夹。

安装后，用同一浏览器个人资料打开 http://127.0.0.1:18765/ 并刷新。首次弹出授权窗口时点击“允许本站连接”，保存成功后窗口自动关闭。不能从内置预览浏览器读取另一浏览器的 Cookie；不支持的浏览器可使用手动导入。

不需要登录的公开页面，可取消上方勾选直接收集。插件不可用时，仍可在下方粘贴导入。

手动导入本站 Cookie（备用）

自动获取失败时，先填写上方网址，再粘贴本站 Cookie JSON 或选择文件导入。

粘贴和文件二选一。成功导入后会自动清空输入框。

②点击按钮，等待完成

将保存网页当前可见的文字和图片。会员页面可保存试读部分，并注明“部分内容”。

请先粘贴一个网址，再点击上方按钮。

③下载收集好的内容

Markdown 保留正文排版；需要连同图片保存，请选“下载图文包”，解压后双击“打开阅读.html”即可查看。文件名自动使用网页标题和采集时间，不再固定。

收集完成后，这里会出现下载按钮。

需要登录或验证？打开浏览器处理
点击打开 → 在弹出的浏览器里自行登录或验证 → 看到您需要的正文后，回这里点击“保存当前页面”。登录状态保存在本机，后续采集本站时可使用。不会自动填写账号密码，也不能保证所有网站都能通过验证。
