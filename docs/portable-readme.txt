网页资料收集助手 · Windows 便携版

1. 将整个压缩包解压到本地文件夹（不要在压缩包内直接双击）。
2. 双击“启动.bat”。首次启动需解压内置环境，请耐心等待几分钟，不需要联网安装。
3. 浏览器打开后，按页面上的 ①②③ 操作。

无需安装 Python、Conda 或 Docker。需要 Windows 10/11 64 位，以及约 3 GB 可用空间。
访问网页仍需网络；本站是否允许采集取决于网站。需要登录时，请使用自己的账号。
首次准备完成后不要移动文件夹；需要换位置，请重新解压原始压缩包。
运行期间请保留启动窗口，关闭窗口即停止服务。端口为 18765，不使用 5173。
如果浏览器未自动打开，可手动访问 http://127.0.0.1:18765/。
若公司安全策略阻止脚本或内置浏览器，请联系公司管理员批准，不要关闭安全软件。

本包不包含发送者的 Cookie、账号状态、浏览器个人资料、采集结果。
自己使用后，app/sessions、app/browser_profiles 和 app/data 会产生本地数据，勿再次整体转发。
图片与文档的授权范围、会员限制不会因为使用便携版而改变。
