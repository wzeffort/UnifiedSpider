# 2.0 验证记录

## 2.1 增量验证

- test_site_access.py：空/过期/跨站 Cookie 检查、SQLite 跨页面暂停、JSON 40362 检测、指定回答正文提取，通过。
- test_backend.py：跨任务暂停确实阻止下一次 HTTP 请求；持久化操作浏览器、人工确认后后台会话复用，通过。
- test_browser.py：公开网页采集、字段点选、四种格式实际下载及浏览器脚本检查，通过。
- 未测试知乎真实账号，不保证知乎解除访问限制或所有回答都能采集。

验证日期：2026-09-15，Windows + spider-crawl4ai Conda 环境。

| 场景 | 验证方式 | 结果 |
| --- | --- | --- |
| 公开网页采集 | 浏览器界面提交 example.com | 通过 |
| 字段点选、保存 | 实际点击快照标题并提取 | 通过 |
| TXT/CSV/JSON/Markdown | 实际点击下载并等待完成、检查文件内容 | 通过 |
| 动态空白页 | 受控页面 JS 延迟渲染；确认切换到浏览器引擎 | 通过 |
| 临时 HTTP 503 | 受控服务首次 503、第二次 200，确认请求次数 | 通过 |
| HTTP 403 | 确认为需要用户操作，不反复请求 | 通过 |
| 单页失败与恢复 | 首页面成功、第二页失败；修复后重试不重抓第一页 | 通过 |
| 同站、下一页链接 | 受控两页实际浏览器/HTTP 采集 | 通过 |
| 后台队列 | 两个慢任务并行、第三个排队、取消第三个 | 通过 |
| 人工确认页面 | 未确认时不保存，确认后生成结果 | 通过 |
| 登录会话复用 | 测试站 Cookie 会话，后续浏览器请求可访问私有测试页 | 通过 |
| 可见浏览器接口 | 实际打开浏览器子进程、确认并保存 | 通过 |
| 手动粘贴备用入口 | 保存、导出 TXT 并核对内容 | 通过 |
| 本机 POST 请求保护 | 错误令牌拒绝 | 通过 |
| Python 依赖兼容 | pip check | 通过 |

以上测试证明对应机制工作，不代表已经覆盖“大部分网站”。
知乎真实账号登录后的采集未验证，也未自动操作用户账号。
通用网站支持率需要根据用户常用网站列表逐站测试；付费权限、复杂交互、验证码、非 HTML 文档另有边界，见 README。
