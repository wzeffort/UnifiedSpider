## 安装

1. Edge 打开 edge://extensions，Chrome 打开 chrome://extensions。
2. 暂时关闭旧的“网页资料收集助手 · 本机连接”扩展，避免两套桥接同时回应。原商店版 Cookie-Editor 可以先停用，不必卸载。
3. 开启开发人员模式，点击“加载解压缩的扩展”，选择本文件所在文件夹（含 manifest.json）。
4. 在同一个日常浏览器个人资料中打开 http://127.0.0.1:18765/，刷新并输入网址。
5. 首次会弹出 Cookie-Editor 本机授权窗口，点击“允许本站连接”。成功保存到本机后自动关闭该授权窗口，工具显示绿色获取结果；保存失败时不关闭。以后该站点后台同步，不再弹窗。

点击扩展图标仍是原来的 Cookie-Editor，原 Export → JSON、编辑等功能保留。原浏览器网站登录状态不变。
新增“保存并下载 Markdown”按钮：保持本机工具页面打开，在文章标签页完成验证并看到正文后，点击扩展图标和该按钮，直接读取当前页面并保存到本机工具，不重新请求文章，不需要先同步 Cookie。微信公众号仅提取正文区域，验证页不保存。保存后自动发起以文章标题命名的 Markdown 下载，无需切回工具；按 Ctrl+J 查看下载，工具仍保留采集记录。图片保留原链接，不下载图片。更新时需确认新增的 activeTab / scripting 权限；正文仅发往本机 18765 服务。
无法静默升级商店版；修改版需单独加载，商店不会自动更新本副本。以后更新本目录后，在扩展管理页重新加载。

## 变更与数据边界

- 新增 manifest.json、collector-background.js、collector-content.js、collector-authorize.html/js；cookie-editor.js 仅新增桥接模块导入。
- 保留原 Cookies API 权限和编辑/导出界面。自动传给采集工具还需按站点独立同意，并不因原有所有网站权限而直接全量导出。
- 只接受本机 18765 根页面的请求，按 URL 过滤 Cookie，使用当前个人资料的 Cookie store，跳过分区 Cookie。
- Cookie 不返回网页消息、不写入扩展存储或日志，仅发给本机带令牌的导入接口。网站授权记录存本机扩展，浏览器本身持有 Cookie。
- Cookie 存在不保证登录有效，也不绕过会员权限或网站限制。
- 要撤销授权，可在该站授权窗口点击撤销，或移除此修改版。工具已有的本地会话副本不随扩展移除而自动删除。
- 可直接加载源码，无需 npm install。附带上游开发配置，未发布、未上传 GitHub、未修改您已安装的商店插件。

1.14.3：支持本机网页“按作者批量下载”，新增 author-batch.js。仍需先允许本站连接；由工具逐步驱动已授权站点的列表加载和正文保存，验证由用户处理，不保证全部历史。可暂停续传并下载 Markdown 合集 ZIP。

批量任务现在由同一个工具页复用一个后台工作标签页，跨作者、列表和正文阶段复用，不按文章数量累积标签页；遇验证才激活工作页。只操作扩展创建的工作页，不替换日常标签页。

资料包同时包含 `documents.jsonl`（UTF-8，每行一篇文章）、每篇 Markdown、采集清单及 RAG 导入说明。JSONL 保留 document_id、source_url、platform、author_id、title、text、markdown、captured_at、content_hash、partial_content 和图片链接。作者名称和发布时间未可靠提取时为 null；采集时间不能当作发布时间。旧记录的采集时间可能为空。建议入库时按标题／段落切块，再生成向量；可在本机工具中另行下载图片或使用 MinerU 云端识别图片（需要本机配置 API 凭据），不生成 embedding。

本机网页可选择 RAG 资料保存目录。文件夹模式直接由本机服务写入 JSONL 和 Markdown，并写入 export.json 就绪标记；无需浏览器决定下载路径。保存设置在网页完成，无需扩展增加文件系统权限。

新版保留页面明确提供的作者和发布时间元数据；更新扩展后请重新加载。


历史发现与自动处理更新：新版扩展支持下一页、加载更多、内部滚动容器；滚动未到底时不会因 6 轮无新增而结束。只有达到篇数上限或页面连续确认末尾才自动保存正文；卡住时暂停并提示检查，不冒充全部完成。历史任务可在详情中“继续发现历史”，保留已保存文章，从新增链接继续。

新任务默认启用“采集完成后自动识别图片并保存资料”。后端串行排队调用 MinerU，使用任务开始时选择的目录；关闭网页不会中止后处理，服务重启会恢复排队或未完成的后处理。识别失败仍保存成功资料和错误标记，提供“重试识别并保存”。浏览器下载模式需要网页保持打开；需要完全后台保存请选本机目录。该更新需要重新加载 Cookie-Editor 1.14.3 或独立版 1.5.3。
